플랫폼 손익 산식
- 청구매출: lead_supply_ledger의 billable=true 행에 저장된 unit_price_snapshot 합계
- 등록 광고비: 각 로펌 정산설정의 adSpendEntries 중 해당 월 금액 합계
- 순이익: 청구매출 - 등록 광고비
- DB 원가: 등록 광고비 / 공급 DB
- 수임전환: 해당 월 공급 DB 중 convertedClientId 또는 convertedCaseId가 생성된 DB

※ 결제/수금 전용 플랫폼 원장이 아직 없으므로 플랫폼 화면은 '청구매출' 기준입니다.
  실제 입금/미수까지 플랫폼 수익에 반영하려면 추후 플랫폼 청구·수금 원장을 별도 추가하면 됩니다.

2. 정산설정 저장 오류 재수정
- 브라우저에서 firm_settings를 직접 저장하지 않음
- /api/admin/management-settings 서버 API에서 로그인/관리자/로펌 범위를 검증한 뒤 service role로 저장
- 로펌관리자: 자기 로펌만 저장
- SUPER ADMIN: 선택한 로펌만 저장
- 실패 시 Supabase 실제 오류 메시지/코드가 화면에 전달되도록 보강
- 기존 /api/management-settings가 없어도 이번 버전의 새 API로 저장됨

이제 주말 오전/오후 조건을 선택해도 저장 후 유지되고 실제 자동배정 규칙에 사용됩니다.

4. 010 SQL 권한 오류 수정본 포함
기존 오류:
P0001: DB 기본정보 수정 권한이 없습니다.

원인:
과거 consultTime 교정 UPDATE가 app_leads 권한 트리거에 막힘.

수정:
과거 데이터의 consultTime 1개 키를 교정하는 구간에서만 관련 권한/정규화 트리거를 잠시 비활성화한 뒤 즉시 복구.
담당자 / 진행단계 / 상담일지 / 상담 후 방향 / 예약 / 계약정보는 수정하지 않음.

적용 후 확인
- SQL 마지막 결과 weekend_still_mapped_to_weekday = 0 확인
- 직원계정관리 > DB 자동배정 > 상세규칙 > 상담가능시간에 주말 오전/오후 표시 확인
- 정산설정에서 값 변경 > 설정 저장 > '저장됨' 확인
- 로파워 플랫폼 > 플랫폼 손익 탭에서 월별/로펌별 지표 확인
