LawPower v28.4 SUPER ADMIN CONTROL CENTER

기준:
- v28.3 멀티로펌 SQL(006_multi_tenant_platform.sql) 적용 완료 후 코드 업데이트용
- 추가 SQL 없음

핵심 추가:
- SUPER ADMIN 통합 관제센터 확장
  · 전체 로펌 / 직원 / DB / 계약 / 24h 실제공급 / 과금 / 활동 / 연동오류 집계
  · DB 공급관리 / 광고연동 모니터링 / 전체 활동로그 탭
  · 24h 공급 집계에서 migration backfill 제외
- 로펌 상세 관제 페이지 /platform/firms/[id]
  · 최근 DB / 계약 / 직원 / 최근 로그인 / 업무변경 / 플랫폼 감사로그
  · 공급원장 / 중복·재유입 / Sheet / Meta / 광고소스 / Queue / 수신오류 확인
  · 기본정보 수정 / 활성·이용정지 / 로펌 설정 진입
- SUPER ADMIN ‘로펌 어드민 보기’
  · 해당 로펌 범위로 DB/고객/계약/분납/정산/설정/직원관리 데이터를 제한해서 로드
  · 모든 업무권한으로 직접 조회/수정 가능
  · 신규 데이터 저장 시 선택 로펌 law_firm_id 자동 부여
  · 상단 SUPER ADMIN 관리중 배너 + 플랫폼 복귀
- 직원계정관리
  · SUPER ADMIN 로펌 범위에서 해당 로펌 직원만 표시
  · 로펌 관리자/직원 직접 생성, 역할/활성/세부권한/DB자동배정 수정
- SUPER ADMIN 로펌 진입/종료를 platform_audit_logs에 기록

보안 원칙:
- SUPER ADMIN은 모든 테넌트 접근 가능하지만 ordinary CRM 화면에서는 반드시 선택한 로펌 한 곳만 브라우저에 로드합니다.
- 로펌 간 데이터 혼합 방지를 위해 저장/삭제도 선택된 law_firm_id 범위로 제한합니다.
- 실제 로펌 삭제 기능은 제공하지 않고 이용정지/활성화로 운영합니다.
