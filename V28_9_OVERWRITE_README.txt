LawPower v28.9 덮어쓰기 파일

적용 내용
- 상담 후 방향:
  개인회생 / 개인파산 / 워크아웃 / 법인회생 / 일반회생 / 기타사건
- 계약관리 상단 유형 메뉴 동일 6종
- 계약 등록 사건유형 동일 6종
- DB 고객전환 시 상담 후 방향이 계약유형으로 그대로 승계
- DB관리 피벗 상담가능시간에 주말 오전 / 주말 오후 추가
- 실 월소득 피벗에 무직 추가
- 기존 DB의 raw 문구가 조금 달라도 기존 피벗 범주로 자동 매칭
- 상담일지 직군이 무직인 고객도 무직 필터에 포함
- 대시보드/데이터집계 사건유형 통계도 6종 반영

사용 방법
1. ZIP 압축 해제
2. 압축 안의 app / components / lib 폴더를 기존 maeil 프로젝트 루트에 그대로 복사
3. 파일 덮어쓰기 선택
4. npm run build
5. 이상 없으면 배포

SQL 실행은 필요 없습니다.
패치 스크립트가 아니라 완성된 수정 파일 자체가 들어 있습니다.
