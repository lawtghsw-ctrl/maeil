# 로파워 Admin Demo v1

회생·파산 업무를 우선으로 한 로펌 통합 Admin 기능 데모입니다.

## 기준
- 업무 UX: 기존 도원 Admin v23의 좌측 메뉴 / 게시판형 목록 / 상세 팝업 / 검색·필터 / 일정·이력 구조
- 대시보드·브랜드: 로피 고객사/운영사 대시보드 목업 및 개발반영 스펙의 디자인 토큰과 기간·결제·정산 개념
- 회생·파산 업무: 상담일지 구조, 업무매뉴얼, 서류 제출안내의 인적사항·소득·재산·채무·변제계획·15종 서류·사건진행

## 구현한 메뉴
- 대시보드
- 신규 상담 DB
- 상담 / 고객 관리
- 파이프라인
- 오늘의 일정
- 계약 관리
- 청구 / 결제
- PG / 정산 데모
- 서류 수합
- 사건 진행
- 데이터 집계
- 내부 게시판
- 기간별 변동내역
- 기준표 / 설정

## 데모 범위
- 브라우저 localStorage 저장
- 실제 Supabase / PG / Toss / AI / 전자계약 API는 연결하지 않음
- 모든 이름·전화번호·금액은 기능 확인용 가상 데이터
- 예상 변제계획은 상담 참고용 기능 데모이며 법률판단을 대신하지 않음

## 실행
```bash
npm install
npm run dev
```

## 빌드

