# 회생·파산 업무관리 Admin DEMO V2

개인회생·개인파산 상담용 기존 구글시트 업무구조와 내부 Admin UX를 참고해 만든 **독립 기능 테스트용 DEMO**입니다.

## 데모 원칙
- 특정 법률사무소/회사 상호명 없음
- 실제 고객정보 없음 (모든 이름·번호·사건번호는 가상 DEMO)
- Supabase/API/Meta/eformsign 실연동 없음
- 브라우저 `localStorage`만 사용
- `데모 데이터 초기화`로 언제든 초기 상태 복원
- JSON 내보내기로 현재 테스트 상태 백업 가능
- 계산 기준은 기능 테스트용 DEMO 값이며 실제 법률판단용 기준이 아님

## V2 핵심 변경
- 고객(Person)과 상담/사건(Matter) 분리: **고객 1명에 복수 상담사건 가능**
- 기존 상담시트 상태값 기반 파이프라인 확장
- 다음액션일·다음액션유형 및 `오늘의 일정` 메뉴
- 고객 상세 통합 탭
  - 요약
  - 인적사항
  - 소득
  - 재산
  - 채무
  - 회생 예상계산
  - 상담내역 Timeline
  - 계약
  - 서류
  - 사건진행
- 재산/채무를 행 단위로 복수 등록
- 회생 예상계산: 월 가용소득 / 청산가치 / 최종 월변제 / 예상 탕감액·탕감률 / 상담 참고 판정
- 기준표/설정 메뉴에서 가구원수별 DEMO 기준금액 관리
- 소액임차인 최우선변제 DEMO 조회 도구
- 세금·건보 50% 참고계산 도구
- 상담 가이드 사이드패널
- 상담 Timeline
- A4 가로 상담카드 인쇄/PDF용 화면
- 동일 전화번호 고객 중복 생성 방지 및 기존 고객에 새 상담사건 추가
- 파이프라인 칸반 보기

## 서류 수합
계약 생성 시 DEMO 기본 15종 서류 체크리스트가 자동 생성됩니다.
상태값: `미수령 / 요청 / 수령 / 보완필요 / 해당없음`

## 실행
```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속.

## 검증
```bash
npm run build
npm run lint
```

현재 전달본은 소스 정적/TypeScript 구조 검증을 수행했으며, 이 작업 환경에서는 npm 패키지 설치가 네트워크 타임아웃되어 실제 Next.js build는 실행하지 못했습니다.
