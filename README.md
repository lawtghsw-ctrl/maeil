# 회생·파산 Admin DEMO v3

기존 사채 Admin의 반응형/업무관리 방식과 회생·파산 상담 업무매뉴얼, 기존 구글 상담시트 구조를 결합한 **완전 독립형 기능 테스트 데모**입니다.

## 핵심 특징
- 회사명, 실고객, 실계좌, 실 API가 없습니다.
- Supabase/Meta/eformsign 실연동 없이 `localStorage`로 CRUD 테스트가 가능합니다.
- 동일 고객에게 여러 상담/사건을 연결할 수 있습니다.
- 신규 상담 DB / 고객관리 / 파이프라인 / 오늘의 일정 / 계약 / 입금 / 서류 / 사건진행 / 분석 / 계산기 / 설정 / 변동내역 / 게시판을 제공합니다.
- 고객 상세에서 인적사항·소득·재산·채무·예상변제·상담타임라인·계약·입금·서류·사건진행을 한 화면에서 확인할 수 있습니다.
- 상담카드 A4 가로 인쇄 기능이 있습니다.

## 실행
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:3000` 접속.

## DEMO 계산기 주의
가구원수별 기준금액 및 소액임차인 참고값은 **기능 테스트용 데모 값**입니다. 법률 실사용 전 반드시 해당 연도 공식 기준을 검증해 설정에서 교체해야 합니다.

## 데이터 초기화
좌측 하단 **데모 데이터 초기화**를 누르면 최초 샘플 상태로 복구됩니다.

## 데이터 내보내기
좌측 하단 **JSON 내보내기**를 누르면 현재 데모 데이터를 JSON 파일로 저장합니다.
