# maeil 회생·파산 Admin Demo v1

기존 사채 Admin(`admin-edit-safe-refresh-v23`)의 화면 구조와 업무형 UX를 베이스로 개인회생·개인파산 상담/사건관리 데모로 전환한 버전입니다.

## 방향
- 기존 Admin의 좌측 메뉴, 상단 검색/알림, 표형 게시판, 상세 팝업, 모바일 테이블 UX를 유지
- 새 SaaS 카드형 UI가 아니라 기존 사채 Admin과 같은 업무용 게시판 중심
- 실제 회사명, 실제 의뢰인, 실제 API, Supabase, 전자계약 연동 없음
- 브라우저 localStorage 기반 데모 데이터

## 주요 메뉴
- 대시보드
- 신규 상담 DB
- 상담 / 의뢰인 관리
- 계약 관리
- 입금 / 분납 관리
- 서류 수합
- 사건 진행
- 내부 게시판
- 기간별 변동내역
- 데이터 집계
- 기준표 / 설정

## 핵심 동작
1. 신규 상담 DB 등록
2. `의뢰인 등록` 버튼으로 상담 / 의뢰인 관리 이관
3. 의뢰인 상세에서 인적사항/소득/재산/채무/예상 변제계획/상담내역/서류/사건진행 관리
4. 서류 수합 화면은 `의뢰인 선택`만 하면 최근 사건 자동 연결
5. 사건 진행은 게시판 기본행 + 우측 펼치기 버튼으로 상세 정보 노출
6. 계약/입금/상태변경/메모 이력을 데모 변동내역에 기록

## 주의
예상 변제계획과 기준표 값은 기능 테스트용 추정치이며 실제 법률판단 또는 공식 산정값이 아닙니다.
