[핵심 변경]
1. 대시보드
- 최고관리자: 계약 1건당 순이익, 회수매출, 계약/월목표, 회수율, DB/광고비, 인건비, 미수금, 현금영업이익
- 활성 DB 상한 초과 / 장기 방치 DB / 연체 위험 경고
- 일반 직원은 기존 실무형 KPI/투두/캘린더 유지
- SUPER_ADMIN 전체보기는 활성 로펌별 설정을 합산해 비용/목표 계산

2. 데이터집계
- 최고관리자 전용
- 6개 탭: 요약 / 팀·인원 / 상담 운영 / 광고·소재 / 수임·매출 / 사건·수납
- DB 생산성, 기여이익, 첫 활동 속도, DB당 컨택, 할인율, 단순분납 비율, 연체 등 표시
- 광고 직접 운영 로펌: 실제 광고비 기준
- DB 구매 로펌: DB 구매비 기준(로파워 내부 광고 원가 비노출)
- 계약 원장 CSV / XLSX(계약별 원장 + 상담사별 합계) 다운로드

3. 정산
- 계약매출 / 회수매출 / 미수금 / 인건비 / DB·광고비 / 결제수수료 / 고정비 / 현금영업이익
- 현금 손익 브리지
- 상담사별 보상액 및 기여이익
- 입금별 수수료/실수령액 표시 및 CSV

4. 정산설정
- 최고관리자 전용
- 광고 직접 운영 / DB 구매 모드
- 월 계약 목표
- 활성 DB 상한 / 방치일 / 최소 컨택 기준
- 사건유형별 기준수임료·최저수임료·할인승인 기준·적용시작일
- 상담사별 정규직/프리랜서, 기본급, 성과급 기준/금액, 해지환수 여부
- 광고비 기간·소재별 입력
- 결제수단별 수수료율/부담주체
- 월 고정비
- 월 마감 / 해제 및 마감 시점 계산조건 스냅샷 고정

[적용 순서]
1) 이 압축파일을 프로젝트 루트에 풀고 동일 파일을 덮어쓰기
2) Supabase SQL Editor에서 supabase/migrations/008_management_analytics.sql 전체 실행
3) 로컬 프로젝트에서 npm run build
4) 빌드 성공 후 Vercel 배포

[주의]
- SQL 실행 전 파일만 덮어쓰면 management_analytics_v1 설정 RLS/default가 없어 관리자 설정 저장이 정상 동작하지 않을 수 있습니다.
- 기존 고객/DB/계약 데이터는 삭제하지 않습니다.
- 해지/환불 '금액' 전용 필드는 현재 스키마에 없으므로 실제 환불액을 임의로 계산하지 않습니다.
