LawPower v28.17 · 주말 상담가능시간 피벗 + 검색 수정

[수정 내용]
1. 상담가능시간 피벗
- 주말 오전 -> 주말 오전(8시~12시)
- 주말 오후 -> 주말 오후(12시~19시)
- Meta 인스턴트 양식의 공백/괄호 유무와 무관하게 동일 값으로 정규화
- 주말 값을 평일 오전/점심/오후로 잘못 분류하던 기존 SQL 정규화 순서 수정

2. 신규 Google Sheet DB 연동
- consultTime을 exact match가 아니라 정규화 함수로 변환
- consultTimeRaw 원본 응답은 항상 보존
- 앞으로 들어오는 주말 DB는 주말 오전/주말 오후로 정상 등록

3. 기존 DB 복구
- 010_weekend_consult_time_search_fix.sql 실행 시 기존 DB의 상담가능시간을 원본 consultTimeRaw 기준으로 재판정
- 수정되는 값은 app_leads.data.consultTime 한 항목뿐
- 상담 후 방향 / 담당자 / 진행단계 / 상담일지 / 메모 / 예약 / 계약전환 값은 수정하지 않음

4. DB 자동배정 상세설정
- 상담가능시간 조건에 주말 오전(8시~12시), 주말 오후(12시~19시) 추가
- 기존 저장 규칙의 '주말 오전/주말 오후'는 새 표기로 자동 승계
- SQL에서도 기존/신규 슬롯을 같은 정규화 기준으로 비교

5. 검색 수정
- 최상단 검색창: DB 리드 + 계약 고객을 함께 검색
- 직원은 본인 담당 범위, 로펌 관리자는 해당 로펌 전체 범위에서 검색
- DB 결과를 누르면 DB관리로 이동하면서 해당 고객을 자동 검색
- DB관리 담당자 위 검색창: 직원/로펌 관리자 계정에서도 정상 동작
- 검색 입력 시 다른 피벗 필터 때문에 검색결과가 가려지지 않도록 피벗 필터 자동 초기화

[적용 순서]
1. v28.16 적용된 프로젝트 루트에 이 ZIP 내용을 그대로 덮어쓰기
2. Supabase SQL Editor에서 아래 파일 1회 실행
   supabase/migrations/010_weekend_consult_time_search_fix.sql
3. npm run build 확인 후 배포
