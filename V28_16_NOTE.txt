LawPower v28.16 - DB 자동배정 통합설정

1. 직원계정관리 상단에 [DB 자동배정] 버튼 추가
2. 직원 개별 계정 설정에서 자동배정 ON/OFF/순서 입력 제거
3. 별도 팝업에서 해당 로펌 직원 전체를 한 번에 관리
   - 자동배정 참여 체크
   - 기본 배정 순서
   - 직원별 배분 가중치/실제 비율
4. 상세 자동배정 규칙
   - 평일/주말/요일 직접선택
   - 시작/종료 시간 (KST, 자정 넘김 지원)
   - 상담가능시간 피벗 조건
   - 규칙별 배정 대상 및 가중치
   - 상단 규칙부터 우선 적용
   - 1명만 선택하면 해당 조건 DB 100% 몰아주기
5. 기본 규칙/상세 규칙 모두 가중 라운드로빈 적용
6. 설정은 로펌별로 분리 저장

중요: supabase/migrations/009_advanced_lead_assignment.sql 을 Supabase SQL Editor에서 1회 실행해야
시간대/비율/상세 규칙이 실제 신규 DB 자동배정에 적용됩니다.

기존 직원 auto_assign_leads / lead_assignment_order 값은 최초 기본설정으로 승계되며,
팝업 저장 후에도 호환용 컬럼에 함께 동기화됩니다.
