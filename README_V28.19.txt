LawPower v28.19 — DB 고객정보 등록/계약전환 안정화 + 주말 오전 피벗 최종표기

적용 기준
- v28.18 위에 그대로 덮어쓰기 가능합니다.
- v28.17.x에서 바로 적용해도 v28.18의 플랫폼 손익/정산설정/자동배정 변경 파일을 함께 포함합니다.

이번 수정
1. DB관리 고객 전환 시 app_clients와 app_cases가 동시에 저장되면서 tenant-link 검증이 먼저 실행되어
   간헐적으로 계약 생성이 실패하던 순서 경쟁(race condition)을 DB 레벨에서 허용 가능한 안전한 형태로 수정합니다.
2. DB 전환 권한(db.convert)이 있는 직원은 원본 DB와 동일 로펌/동일 담당자 조건에서
   고객전환용 미접수 계약을 생성할 수 있도록 정책을 보완합니다.
3. 주말 오전 피벗 최종 표기를 정확히 `주말 오전(8~12시)`로 변경합니다.
   주말 오후는 `주말 오후(12시~19시)`를 유지합니다.
4. 예전 저장값 `주말 오전`, `주말 오전(8시~12시)`도 자동배정 설정 API에서 새 값으로 자동 정규화합니다.

Supabase 실행
- 이전 010이 실패했다면: 이 압축의 `supabase/migrations/010_weekend_consult_time_search_fix.sql`을 1회 실행
- 그 다음 `supabase/migrations/011_db_convert_race_fix.sql`을 1회 실행

010 마지막 확인값
- weekend_still_mapped_to_weekday = 0

011은 기존 고객/계약/상담일지 값을 수정하지 않고 정책/검증 함수만 교체합니다.
