LawPower v27.13 변경사항

1. 계약관리 > 상세 > 분납관리
- 총 수임료 / 납부금액 / 납부회차와 함께 결제방법 수정 가능
- 결제방법 저장 시 CaseRecord.paymentMethod까지 Supabase app_cases에 같이 저장

2. DB관리 진행단계/컨택 알림
- 진행단계가 '불가'인 DB 행은 연한 빨간 배경 + 빨간 좌측선으로 표시
- 미상담: 하루 2회 컨택 기준. 당일 재통화(연결) 1회 또는 부재중 2회면 당일 경고 해제
- 부재: 기존 3회 기준을 2회로 조정
- 착수금 안내: 하루 1회 컨택 기준. 당일 재통화 1회 또는 부재중 1회면 당일 경고 해제
- 장기부재: 최근 재통화/부재중 기록 후 3일이 지나면 다시 컨택 알림 표시
- 일일 기준은 KST 00:00에 초기화
- 대시보드 상단 컨택 필요 DB 카운트도 동일 규칙으로 집계

3. 예약 팝업
- 당일 예약만 보이던 고정 예약콜 팝업을 오늘부터 3일 후까지 표시
- 알림벨의 상담예약 알림도 예약 3일 전부터 표시
- 미래 예약은 날짜+시간을 함께 표시

4. 고객/계약 상세
- 상단 업무버튼에 '최우선변제 안내표' 추가
- 클릭 시 첨부 이미지 기준의 현행/개정안 표를 팝업으로 표시

DB 스키마 변경 없음 / 추가 SQL 실행 없음.
