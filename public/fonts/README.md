# PDF Korean font

`NanumGothic-Regular.ttf` is the unmodified Nanum Gothic Regular font from the
Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/nanumgothic

Copyright (c) 2010, NHN Corporation. Distributed under the SIL Open Font License
1.1; see `NanumGothic-OFL.txt` for the full license and reserved names.

The consultation PDF export fetches this local static asset only after the user
clicks the PDF download button. Customer information is never sent with the request.
