LawPower v28.26 — 계약관리 삭제 버튼

적용 내용
- 계약관리 목록(PC/모바일)에 빨간 삭제 버튼 추가
- 계약 상세 상단에도 계약 삭제 버튼 추가
- 삭제 전 고객명/사건번호 확인 팝업 표시
- 계약 삭제 시 해당 계약의 분납 일정과 계약 일정도 함께 삭제
- 고객정보와 원본 DB는 보존
- 원본 DB의 convertedCaseId만 정리하여 필요 시 계약 재생성 가능
- 직원계정관리 > 계약관리 그룹에 '계약 삭제(cases.delete)' 권한 추가
- 일반 직원 기본/프리셋에는 삭제 권한을 자동 부여하지 않음
- 로펌 관리자/최상위 관리자는 기존 관리자 권한으로 삭제 가능
- DB RPC에서 권한/로펌/담당범위를 재검증하고 한 트랜잭션으로 삭제

이 ZIP은 v28.25 저장 안정화 패치를 포함한 누적 덮어쓰기 패치입니다.
아직 017을 실행하지 않았다면 017_staff_save_reliability.sql 실행 후
018_case_delete_permission.sql을 실행하세요.
017을 이미 실행했다면 018만 실행하면 됩니다.
